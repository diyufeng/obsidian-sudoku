# Sudoku

在 Obsidian 笔记中直接渲染数独棋盘。将棋盘写成 ` ```sudoku ` 代码块，插件会渲染为带九宫粗边框的 9×9 网格，可选配行列序号，并为原题数字、填写答案、错误尝试、备选数提供不同的显示样式。

## 特性

- **代码块渲染器** —— 与 Obsidian 内置 `mermaid` 处理器机制一致，使用 ` ```sudoku ` 围栏即可。
- **棋盘元数据** —— 通过 `#key: value` 行声明标题、难度、说明、尺寸、底色开关。
- **三档尺寸** —— `small`（26px 单元格）、`medium`（38px，默认）、`large`（52px），字号与边框粗细按比例联动。
- **单元格类型** —— 原题（黑色）、正确答案（蓝色）、错误答案（红色）、空白（无数字）。
- **重点单元格** —— 用橙色背景标记需要关注的格子。
- **备选数** —— `{123}` 渲染为 3×3 小网格，数字按 1-9 自然位置填入（1 左上角、9 右下角）。
- **偶数宫底色** —— 可选的隔宫阴影，便于扫视。
- **行列序号** —— 上方与左侧显示 1-9 序号，其余三侧留白。
- **明暗主题适配** —— 边框与底色自动切换。
- **插入模板命令** —— 命令面板中一键插入可编辑的数独代码块。

## 安装

### 从 Obsidian 社区插件市场

1. 打开 **设置 → 第三方插件**。
2. 点击 **浏览**，搜索 "Sudoku"。
3. 安装后启用。

### 手动安装（BRAT / 测试版）

1. 安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件。
2. 在 BRAT 中添加本仓库地址。
3. BRAT 会自动安装并保持更新。

### 从源码构建

```bash
npm install
npm run build
```

将 `main.js`、`manifest.json`、`styles.css` 复制到 `<vault>/.obsidian/plugins/sudoku/`，然后在 **设置 → 第三方插件** 中启用。

## 用法

使用 `sudoku` 语言标记的代码块即可。命令面板中的 **"插入数独代码块模板"** 会一键插入完整示例。

### 元数据（可选，写在代码块顶部）

| 键                | 说明                                              | 默认值    | 是否显示在棋盘上方 |
|-------------------|---------------------------------------------------|-----------|--------------------|
| `#title`          | 标题                                              | —         | 是                 |
| `#difficulty`     | 难度（渲染为 `难度: <值>`）                       | —         | 是                 |
| `#note`           | 自由说明（保留换行）                              | —         | 是                 |
| `#size`           | `small` / `medium` / `large`                      | `medium`  | 否                 |
| `#show-background`| `true` / `false`，是否为偶数宫加底色              | `false`   | 否                 |

值为空时忽略，未知键忽略。

### 单元格 token

每个单元格是一个空白分隔的 token。前缀可任意顺序组合。

| Token     | 含义                                                |
|-----------|-----------------------------------------------------|
| `5`       | 原题数字（黑色）                                    |
| `*5`      | 正确答案（蓝色）                                    |
| `!5`      | 错误答案（红色）                                    |
| `$5`      | 重点单元格（橙色背景）                              |
| `$*5`     | 重点 + 正确答案                                     |
| `.`       | 空白格                                              |
| `{123}`   | 空白格 + 备选数 1、2、3（渲染为 3×3 网格）          |
| `${123}`  | 重点 + 备选数                                       |

#### 组合规则

1. **`*` 与 `!` 同时存在** → 单元格类型为 `wrong`（`!` 优先），与前缀顺序无关。`*!5` 和 `!*5` 都渲染为红色 5。
2. **数字与 `{备选数}` 同时存在** → 若 token 含 `*` 或 `!`，则忽略数字、显示备选数；否则忽略备选数、显示数字。

   | Token      | 渲染结果                                     |
   |------------|----------------------------------------------|
   | `5{123}`   | 原题 5（备选数忽略）                         |
   | `*5{123}`  | 备选数 1、2、3（数字忽略）                   |
   | `!5{123}`  | 备选数 1、2、3（数字忽略）                   |
   | `*!5{123}` | 备选数 1、2、3（数字忽略）                   |

3. **备选数去重** —— `{}` 内的数字会去重并排序。`{99112}` 等价于 `{129}`。
4. **无法识别的 token** 按空白格处理。

### 分隔横线

以 `-` 开头的行（例如 `------+-------+------`）会被忽略，因此可保留传统数独排版的分隔横线以提升可读性。


## 开发

```bash
npm run dev     # esbuild 监听模式
npm run build   # 类型检查 + 生产构建
```

项目结构：

- `src/main.ts` —— 解析器、元数据提取、HTML 渲染
- `styles.css` —— 所有样式，由 `.sudoku-wrapper` 上的 CSS 变量驱动
- `esbuild.config.mjs` —— 打包配置
- `tsconfig.json` —— TypeScript 配置

### 样式扩展

所有尺寸由 `.sudoku-wrapper` 上声明的 CSS 变量驱动。新增尺寸档位只需声明 `.sudoku-wrapper.size-xlarge` 类并覆盖 `--cell`、`--label-size`、`--num-size`、`--cand-size`、`--thick`。仓库内 `.trae/skills/obsidian-plugin-css-wrapper/SKILL.md` 记录了本项目使用的 wrapper 隔离模式。

## 兼容性

- Obsidian **1.4.0** 及以上。
- 明暗主题均适用。
- 桌面端与移动端均可用（不依赖 Node 专属 API）。
